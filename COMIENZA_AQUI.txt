❓ PREGUNTAS FRECUENTES:

P: ¿Necesito instalar algo?
R: Para la página web: NO. Para Docker: SÍ (descarga Docker Desktop)
   Para Google Cloud: SÍ (descarga Google Cloud SDK)

P: ¿Cuánto tiempo toma todo?
R: Depende:
   - Solo página web: 1 hora
   - Página + Docker: 2-3 horas
   - Todo completo: 3-4 horas

P: ¿Cuesta dinero?
R: NO. Google Cloud da $300 gratis el primer año.
   Tu app cuesta $0 si tienes pocos visitantes.

P: ¿Qué pasa si cometo un error?
R: ¡NADA! Puedes:
   - Ctrl+Z para deshacer en código
   - Reconstruir Docker
   - Re-desplegar en Google Cloud
   Eres principiante, cometer errores es NORMAL y ÚTIL. 🎓

P: ¿Dónde pido ayuda?
R: 1. Lee INDICE.md para encontrar documentación
   2. Abre F12 en el navegador para ver errores
   3. Copia el error en Google
   4. Pregunta a Copilot en VS Code
   5. Pide ayuda a tu profesor
