## 🔧 Comandos Comunes

Si pregunta cómo ejecutar algo:

```bash
# Construir Docker
docker build -t mi-pagina .

# Ejecutar Docker
docker run -p 8080:8080 mi-pagina

# Iniciar Google Cloud
gcloud init

# Desplegar en Cloud Run
gcloud run deploy mi-pagina --image gcr.io/[ID]/mi-pagina:latest
```

Siempre acompaña con:
- "¿Tienes Docker instalado?"
- "¿Tienes Google Cloud SDK instalado?"

## ❌ Errores Comunes y Cómo Explicarlos

### "Docker command not found"
```
❌ Significa: Docker no está instalado

✅ Solución:
1. Ve a https://docker.com
2. Descarga Docker Desktop
3. Instálalo
4. Reinicia la computadora
5. Abre PowerShell nuevamente
```

### "Port 8080 already in use"
```
❌ Significa: Otra app está usando ese puerto

✅ Solución:
docker ps          ← Mira qué contenedores corren
docker kill [ID]   ← Detén el que necesitas
```

### "Permission denied"
```
❌ Significa: No tienes permisos para hacer eso

✅ Solución:
- Abre PowerShell como administrador
- O instala todo en una carpeta permitida
```
